## If the walls go blank

1. **Wait 2 minutes.** The system auto-recovers from most crashes within
   that window.
2. If still blank after 2 minutes, **look at the computer monitor** (the
   one on the tech cart / shelf). If you can see a TouchDesigner or
   Resolume window, the system is running — the walls should come back.
3. If you see the Windows desktop on the monitor with no Resolume
   window at all, **text Darren**.
4. If the monitor is asleep: jiggle the mouse gently to wake it (do NOT
   click anything). Just check what's on screen.

**Do NOT restart the computer.** It'll trigger a cascade of startup
sequences and makes things worse, not better.

---

## If the audio goes silent

1. **Check the speakers** — are any cables unplugged or dangling? If a
   speaker cable came loose, plug it back in.
2. **Check the computer monitor** for an Ableton window or a Windows
   Media Player window. If Ableton is running but no sound: text
   Darren.
3. If both audio sources look fine but there's still no sound, it may
   be a Bluetooth speaker that lost pairing. Text Darren.

---

## If a visitor says "I submitted a prompt and nothing happened"

1. Ask them how long they waited. It can take 5–15 seconds to show up
   on the wall.
2. Watch the walls for 30 seconds after they submit — the imagery
   should subtly shift to something matching their prompt (e.g.,
   "herring school" should bring silvery fish).
3. If the prompt never reflects on the wall, **text Darren** with:
   - The approximate time they submitted
   - What words they used (if you remember)
4. Tell the visitor it may take a moment; their dream will arrive.

---

## If a projector shows the Windows desktop or an error

1. Text Darren right away. Don't touch anything on the 3090.
2. While waiting: you can cover the projector opening with the
   diffuser cloth or turn that projector's lens cap on if it's visible.

## If the QR code / visitor submission website is broken

Symptoms: visitors report "the website doesn't load" or "my prompt
just sits there".

1. **Test on your own phone**: scan the QR, try submitting a simple
   prompt like "test".
2. If it shows an error, text Darren with a screenshot.
3. If it works for you, the issue is the visitor's wifi/cellular —
   offer them the Mahon Hall wifi password if we have one.

---

## What NOT to do

- **Don't restart the computer** unless Darren tells you step-by-step.
- **Don't close any window** you didn't open yourself.
- **Don't click "Update Windows" or any update dialog.** Close it (X).
- **Don't plug or unplug HDMI / display cables.** These are tuned and
  re-plugging can break everything.
- **Don't run anything with "Admin" in the name.**
- **Don't touch Prav's audio console / Ableton controller.**
