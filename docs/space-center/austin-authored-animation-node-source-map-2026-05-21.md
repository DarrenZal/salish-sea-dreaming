## Protocol

1. Whole-source animation integration is cleaner than applying Austin's
   technique to new generated compositions. The installation should treat each
   Austin GIF as one whole-source animated node, scheduled, held, and revealed
   intact. The renderer is not required to imitate Austin's water motion using
   generated atmosphere.
2. Any technique-application or motion-grammar reuse must wait for Austin.
   "Technique" here means: extracted cascade motion, extracted ripple behavior,
   extracted reed silhouette behavior, extracted curve-of-flow shapes,
   extracted evaporation/vapor patterns, extracted color or palette signature,
   or any model trained on these GIFs. None of those are permitted under the
   current consent floor; they require Austin's explicit per-output approval
   before any internal experiment beyond this map.
3. Whole-source GIFs may participate in the canonical anchor-graph transition
   pattern only as whole nodes:

   ```text
   Artwork -> anchor collapse -> cymatic field -> target gather -> whole artwork reveal
   ```

   Each GIF would expose only two installation contracts: collapse to cymatic
   field, reveal from cymatic field. The cymatic field is the generated
   abstract atmosphere; the Austin GIF remains the whole authored source on
   either side of that field. The cymatic field is not Coast Salish design.
4. Anchors derived from these GIFs (if any) are metadata only. They are not
   renderable, not reusable as motifs, and not approved for external use. No
   anchors have been recorded for these GIFs in
   `track2-deterministic/anchor_graph/austin_anchor_registry_v001.json` at this
   synthesis time.
5. Sequence claims (for example, Phase_01..Phase_09 as a water-cycle order) are
   not part of this map. Frame-count pairings (Phase_03 + Phase_04 both 46
   frames; Phase_05 + Phase_06 both 95 frames) are recorded as measurements
   only, not as confirmed adjacency calls.
