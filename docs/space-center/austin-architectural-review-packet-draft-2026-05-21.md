## 2. Architecture In One Page

The proposed installation architecture is an anchor graph.

Nodes:

- Whole Austin artworks: Austin-authored source works kept intact as whole
  artwork nodes.
- Wave atmospheres: generated wave or cymatic fields that support timing,
  reveal, and atmosphere.
- Water-cycle phrase states: separate support states for water, vapor, rain,
  ripple, current, or related phrase movement.
- Spatial/3D treatments: source-faithful depth or parallax treatments where
  the artwork's authored layers already support figure, field, and depth.

Edges:

- `wave -> artwork`: a generated wave atmosphere reveals or frames a whole
  Austin artwork.
- `artwork -> artwork`: one whole Austin artwork transitions to another whole
  Austin artwork through measured alignment metadata.
- `artwork -> spatial`: one whole Austin artwork is given a source-faithful
  spatial treatment using authored layers.
- `phrase -> phrase`: water-cycle phrase states move among support roles. This
  lane remains unresolved for the current architecture.

Anchors:

- Anchors are metadata only: center points, radii, axis counts, bounds, mask
  order, scale, and timing.
- Anchors are not renderable primitives.
- Anchors are not extracted motifs.
- A shared sun-disc anchor is alignment metadata, not a copied or reusable sun
  motif.

Earlier versions of this packet stated "we are not generating Coast
Salish-style artwork" as a hard prohibition; that framing is withdrawn under
the 2026-05-22 authorization expansion. Updated framing:

- Earlier probes avoided generation; Austin has since given permission for
  generated style/grammar experiments.
- We still distinguish whole-authored Austin source artworks from generated
  Austin-authorized support compositions. Whole sources remain intact;
  generated compositions are clearly labeled as generated and carry the
  `Austin-authorized internal/show-development prototype` label until
  separately cleared.
- We want Austin's curatorial eye on what feels strong, accurate, respectful,
  and useful, and on which generated experiments are working as style/grammar
  exploration versus drifting toward crest invention (which remains out of
  scope).

The installation architecture under test continues to keep Austin's authored
works as whole artwork nodes and use anchor metadata only to choreograph
transitions between whole works. The new authorization adds an in-scope
category for **Austin-authorized generated support compositions** (style
transfer, primitive emergence, anchor-portal renders, etc.); those
compositions are reviewed with Austin as part of his curatorial pass before
any external surface.

## 3. What Changed From Earlier Morph Experiments

Earlier atom and decomposition morphs treated source pieces as raw material for
transition mechanics. That created a failure risk: individual features, atoms,
or motifs could start behaving like reusable assets.

The current anchor approach changes the contract:

- Whole authored works remain intact.
- The renderer does not decompose Austin's art into reusable atoms or motifs.
- The renderer aligns display timing, scale, masks, center points, radii, and
  aperture order using measured metadata only.
- Generated wave and phrase material stays in a support role.
- Austin remains the authority on which works, sequences, anchors, and public
  language are appropriate.

The important distinction is that the system can align whole works without
claiming that shared geometry is shared cultural meaning.
