## Relevant Motifs

### 1. Radial Sun / Central Orb With Attached Rays

Source path:

- `austin-v2-ingest/training/Nature_Cosmic_Sun.jpg`
- `austin-v2-ingest/approved/Nature_Cosmic_Sun.svg`
- `austin-v2-ingest/decomposed/Nature_Cosmic_Sun/atom_metadata.csv`

Observed design logic:

- Dominant central orb first; rays and trigon-like points stay attached to the orb/ring structure.
- Radial pressure is organized by center-out hierarchy rather than scattered ray marks.
- Internal ovoid/crescent face details are part of the authored sun face, not generic sun decoration.

Could inspire:

- A sun/ripple state in the water-cycle system: one central emitter, partial crescent phase arcs around the orb, and attached curved trigon releases.
- Cymatic radial fields where the same structure can read as ripple, radiant field, or snow/rain harmonic depending on context and palette.
- Debug-first topology extraction: central circle, crescent phase cells, trigon/ray release cells.

Requires Austin approval:

- Any public sun/radiant layer that reads as Austin-derived sun grammar.
- Any use of exact sun face geometry, palette, atom adjacency, eye/face details, or source-vector animation.
- Any wording implying that a generated radiant field is Austin-authored or culturally approved.

### 3. Pond Ripple Phrase: Circle -> Crescent -> Crescent -> Trigon

Source path:

- `/Users/darrenzal/Documents/Notes/media/2026-05-18-ssd-meeting-2/06-austin-vancity-slides-crescent-circle-trigon.png`

- `docs/space-center/austin-informed-water-phrase-recipes-2026-05-19.md`

Observed design logic:

- Circle functions as the impact/focal origin; crescents carry ripple phase; trigon marks the final attenuation or release.
- Eye direction is deliberate. The shapes form a phrase, not a field of independent icons.
- The phrase needs proximity, orientation, cupping, and release direction to stay legible.

Could inspire:

- The base water-cycle unit for rain, pond ripple, river knot, current phrase, and cymatic wavefront extraction.
- Validation rules for renderers: every visible mark has a parent origin/path, and phrase order is recoverable from sidecar data.
- Motion staging: circle appears/holds first, crescents propagate, trigon fades or attenuates first.

Requires Austin approval:

- Any public claim that this project has permission to use the primitive phrase as Coast Salish visual language.
- Any rule that fixes traditional meaning to circle, crescent, or trigon.
- Any public output using this adjacency as the main visible grammar.

### 10. Circle / Crescent / Trigon Adjacency And Negative-Space Discipline

Source path:

- `/Users/darrenzal/Documents/Notes/media/2026-05-18-ssd-meeting-2/06-austin-vancity-slides-crescent-circle-trigon.png`
- `docs/space-center/primitive-grammar-contract-2026-05-19.md`

- `docs/space-center/water-cycle-cymatic-primitive-scene-language-2026-05-20.md`

Observed design logic:

- Adjacency carries meaning-like direction for the eye: origin, phase, release, attenuation.
- Crescents need a declared origin/path and intentional cupping. Trigons need an attached release relation.
- Empty channels and gaps must be preserved; filling everything destroys the field logic.

Could inspire:

- Renderer validation: reject random orientation, eye-like circle pairs, decorative scatter, grid tiling, and generic triangles.
- Debug overlays that label origin, cup normal, path tangent, release vector, region type, and cultural status.
- A water-cycle state machine where rain, ripple, snow, mist, and sun all share the same primitive roles but not exact Austin geometry.

Requires Austin approval:

- Any promotion of this adjacency system into public visuals.
- Any use of Austin source atom adjacency as a generic grammar.
- Any figure, face, eye, fish, bird, fin, wing, or cultural-meaning claim built from these adjacencies.
